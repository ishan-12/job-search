## ai-job-search

Some guidance in `.claude/skills/` is derived from prose specifications in
**[MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search)**
at commit `1cdaf94`, used under the MIT licence.

No source file from that project is vendored here. What was taken is a small set
of written rules — the untrusted-posting trust boundary, the interview-backtrack
test, relevance-weighted cutting, the tenure/visible-output heuristic, the
requirement-coverage rule, a company-research checklist, and an interview
question bank — re-authored against this repo's own paths and conventions. This
is a one-time harvest, not a tracked fork: there is deliberately no `upstream`
remote, because this repository is private career data and a remote pointing at
a public repo is one mistyped push away from disclosing it.
