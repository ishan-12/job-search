# Prep Guide

Study material for the technical / AI-strategy portions of VP interviews. Attach this **entire folder** to a Claude Project so you can drill against it conversationally.

## Chapters

| # | File | Covers |
|---|---|---|
| 1 | [01-llm-fundamentals.md](01-llm-fundamentals.md) | Generation loop, attention/transformers, training pipeline, adaptation ladder (prompting/RAG/fine-tuning), model landscape |

## Planned chapters (add as you write them)

- 02 — Cost & performance levers (tokens, prompt caching, routing, latency)
- 03 — Agent architecture & tool use (ADK, MCP, human-in-the-loop)
- 04 — Context management & tool-result hygiene
- 05 — RAG & retrieval pipelines
- 06 — Serving & infrastructure (GPUs, KV cache, quantization, self-hosting)
- 07 — Evals, safety & governance

Each chapter follows the same pattern: every concept explained twice (CEO-facing plain English + principal-engineer technical), grounded in real projects (UniClaw, IAH, TestBOT, CruxOCM), with interview one-liners.

## How to use in a Claude Project

1. Create a Claude Project, attach this folder.
2. Ask it to quiz you, role-play an interviewer, or pressure-test an answer.
3. When you learn a new framing worth keeping, add it back into the relevant chapter here.
